1. fetch_price

Real-Time Cryptocurrency Spot Price, 24h Delta & Volume Aggregator
Paid · x402 $0.005 USDC

Delivers low-latency cryptocurrency spot price, 24-hour percentage change, and 24-hour trading volume lookups powered by CoinGecko primary feeds with automatic Coinbase spot price fallbacks. Ideal for high-frequency portfolio marking and Autonomous Trading Data pipelines.

Parameter Type Required Description & Constraints
coin_id string Yes Asset identifier or ticker symbol (e.g., bitcoin, ethereum, solana, BTC, ETH).
vs_currency string No (Default: usd) Quote currency for valuation (e.g., usd, eur, btc).

2. analyze_volatility

Statistical Z-Score Anomaly Detection & Regime Alert Engine
x402 Pro Signal $0.02 USDC

Computes statistical Z-score volatility anomalies across configurable minute windows (1 to 1440 minutes) and custom sigma thresholds. Classifies real-time market turbulence into NORMAL, MODERATE, HIGH, or CRITICAL alert states so agents can capture Predictive Alpha or halt risky market-making orders.

Parameter Type Required Description & Constraints
coin_id string Yes Target cryptocurrency identifier (e.g., bitcoin, ethereum, solana).
window_minutes integer No (Default: 60) Lookback rolling window in minutes (valid range: 1 to 1440 minutes).
threshold_sigma number No (Default: 2.0) Standard deviation Z-score threshold for anomaly classification (0.5 to 5.0 sigma).
🔗 Tool Endpoint & Schema (/tools/analyze_volatility) 🧪 Live Sample Payload (/tools/analyze_volatility/sample) 📘 Volatility Alert Playbook

3. aggregate_sentiment

Multi-Source Social & News Sentiment Aggregation with Momentum Shifts
x402 Pro Signal $0.01 USDC

Aggregates normalized bullish/bearish sentiment scores (-1.0 to +1.0) across Twitter/X, Reddit, Telegram, and crypto news feeds. Detects narrative acceleration and crowd momentum shifts to enrich On-chain Market Intelligence and pre-trade slippage estimation.

Parameter Type Required Description & Constraints
coin_id string Yes Cryptocurrency identifier to analyze (e.g., bitcoin, ethereum, solana).
sources array<string> No (Default: all) Filter by specific channels: ["twitter", "reddit", "telegram", "news"].
lookback_hours integer No (Default: 24) Historical aggregation window in hours (1 to 168 hours).
🔗 Tool Endpoint & Schema (/tools/aggregate_sentiment) 🧪 Live Sample Payload (/tools/aggregate_sentiment/sample) 📘 Sentiment Slippage Playbook

4. calculate_risk_score

Multi-Factor Asset & Portfolio Risk Scoring Engine
x402 Pro Signal $0.03 USDC

Produces a composite 0–100 quantitative risk rating by weighting realized volatility (40%), order-book & turnover liquidity (25%), market capitalization tier (20%), and Bitcoin beta correlation (15%). Returns automated position-sizing guidance for autonomous treasury managers.

Parameter Type Required Description & Constraints
coin_id string Yes Target crypto asset identifier (e.g., bitcoin, ethereum, solana).
portfolio_allocation_pct number No (Default: 10.0) Proposed portfolio weight percentage (0.1 to 100.0) for concentration-adjusted risk scoring.
risk_tolerance string No (Default: moderate) Agent mandate profile: conservative, moderate, or aggressive.
🔗 Tool Endpoint & Schema (/tools/calculate_risk_score) 🧪 Live Sample Payload (/tools/calculate_risk_score/sample)

5. generate_market_report

Full-Spectrum Executive Market Intelligence Synthesis
x402 Institutional $0.15 USDC

Synthesizes spot price action, Z-score volatility regimes, multi-channel social sentiment, and multi-factor risk scores into a cohesive daily, weekly, or monthly executive brief. Designed for multi-agent orchestrators seeking comprehensive On-chain Market Intelligence and actionable trading theses in a single call.

Parameter Type Required Description & Constraints
coin_ids array<string> Yes List of cryptocurrency identifiers to include in the synthesis (e.g., ["bitcoin", "ethereum", "solana"]).
period string No (Default: daily) Report horizon: daily (24h), weekly (7d), or monthly (30d).
include_recommendations boolean No (Default: true) Whether to include regime-based position sizing and directional alpha signals.
