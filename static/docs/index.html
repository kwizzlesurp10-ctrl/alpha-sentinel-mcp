Alpha Sentinel Documentation & Use-Case Playbooks Hub

Alpha Sentinel is an autonomous-agent-ready On-Chain Market Intelligence server exposing statistical volatility detection, social sentiment aggregation, multi-factor portfolio risk scoring, and executive market synthesis over Model Context Protocol (MCP), Agent-to-Agent (A2A) JSON-RPC, and x402 pay-per-call HTTP settled natively in USDC on Base (eip155:8453).

Zero API keys, zero OAuth handshakes, and zero monthly lock-in required for autonomous agents: discover endpoints via /.well-known/x402 or /.well-known/mcp.json, inspect rate-limited previews at /tools/{tool}/sample, and settle per-request micropayments via PAYMENT-SIGNATURE or AgentCash.

1. Connect via MCP JSON-RPC (POST /mcp)

curl -sX POST https://alpha-sentinel-mcp.vercel.app/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": "init-1",
    "method": "tools/list",
    "params": {}
  }' | jq .

2. Discover & Call via AgentCash CLI (x402 on Base)

# 1. Discover all paid tools and USDC pricing on Base (eip155:8453)
npx agentcash@latest discover https://alpha-sentinel-mcp.vercel.app

# 2. Execute a paid call with automatic 402 challenge signing & settlement
npx agentcash@latest fetch https://alpha-sentinel-mcp.vercel.app/tools/analyze_volatility \
  --method POST \
  --body '{"symbol":"btc","window_minutes":60,"z_threshold":2.0}'

3. Call via A2A Protocol (POST /a2a)

curl -sX POST https://alpha-sentinel-mcp.vercel.app/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": "a2a-1",
    "method": "message/send",
    "params": {
      "skill": "fetch_price",
      "symbol": "eth"
    }
  }' | jq .
