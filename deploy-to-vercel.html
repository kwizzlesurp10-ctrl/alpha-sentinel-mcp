🚀 Deploy Alpha Sentinel to Vercel

✅ You're all set! The code is already on GitHub at:
https://github.com/kwizzlesurp10-ctrl/alpha-sentinel-mcp

Step 1: Go to Vercel

👉 Click here to open Vercel

This will take you to the "Add New Project" page.

Step 2: Import Your Repository

  1. Click "Import Git Repository"
  2. Find or search for: alpha-sentinel-mcp
  3. You should see it in your repositories list (it was just created)
  4. Click "Import"

Step 3: Configure Deployment Settings

Framework Preset: Other

Root Directory: / (leave default)

Build Command:

pnpm --prefix dashboard install && pnpm --prefix dashboard run build

Output Directory:

dashboard/dist
Note: If you don't see these options, Vercel will auto-detect them. Just proceed!

Step 4: Environment Variables (Optional)

For the dashboard alone, you typically don't need environment variables. They're auto-detected.

If you also deploy backend to Render first:

  • Add variable: VITE_API_URL
  • Value: https://your-api.onrender.com

Step 5: Deploy!

  1. Click "Deploy"
  2. Wait ~30-60 seconds for the build to complete
  3. Congratulations! 🎉 Your dashboard is live!

You'll get a URL like: https://alpha-sentinel-mcp.vercel.app

✨ That's it! Your Alpha Sentinel Mission Control dashboard is now live.
It will automatically proxy API calls to your backend when deployed!
